# FACE LAB — 架空の美容医療ケースゲーム

完全に架空の成人キャラクターを使い、顔の特徴・施術の作用・変化の限界・費用・回復過程・リスクを選択式で学ぶ、スマホ／PC対応の日本語ブラウザゲームです（React + TypeScript + Vite）。
現実の患者写真・SNSの顔・有名人・実在人物は使用しません。診断・施術計画・実技の教材ではなく、写真アップロードや「自分の顔の適量判定」機能もありません。

## 起動

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド
npm test           # コンテンツ検証・採点・進捗保存のテスト
npm run prompts    # docs/IMAGE_PROMPTS.md（必要画像一覧＋生成プロンプト）を再生成
node scripts/build-single-html.mjs out.html   # ビルド後、単一HTMLにまとめる
```

## 遊び方

- **モードA リバース・フェイス**：架空の施術履歴を推理。顔（または部位ボタン）→施術を選んで「確認する」。正解すると施術前の画像へ戻る。複数履歴は最後の変更から逆順。誤答は画像を変えず、ヒントと残り試行回数だけ更新。
- **モードB デザイン・チャレンジ**：本人の希望・診察メモを読み、プランを選んで「結果を見る」。「変更しない」「情報を追加する」が正解になるケースあり。唇のように変化の程度（小・中・大）を選ぶケースは、**架空の画像ルール**であり実際の mL・U には換算しません。

## 顔画像の追加方法

1. 画像は **4:5（縦長）** の webp/png/jpg。`src/assets/faces/{状態ID}.webp` の名前で置く（状態IDと必要枚数は `docs/IMAGE_PROMPTS.md`）。置くだけで自動で差し替わります。
2. 「はじめの顔／希望に沿う変化／希望を超える変化」の**3枚組シート**は、切り出しスクリプトで一括変換できます（見出し・注記の帯は自動で除外）。

```bash
pip install pillow numpy
python3 scripts/slice-triptych.py シート.webp C01_base C01_success C01_over
```

3. 人物の外見（肌色・髪型）が画像と食い違う場合は、`src/data/characters.ts` を画像に合わせて更新してください（プロンプト集にも反映されます）。
4. 同じ人物の状態は**全部そろってから**実画像で表示されます（1枚でも欠けると、そのケースは仮イラストで統一）。

## データの構造（UIから独立）

`src/data/` に、出典・用量・価格・回復・施術・人物・出題・画像登録簿を分離して保持しています。

- 出典と事実を対応させ、LLMに足りない医療情報を埋めさせない（確認状況 `EvidenceStatus` を各項目に付与）。
- 用量は `DoseReference` のみに保持し、画像の小・中・大とは結びつけない。添付文書量／試験観察値／販売単位は別欄。
- 価格は原通貨表示。通貨・販売単位・税の扱いを欠落させない。未取得は `null`＝「確認済み掲載例なし」。
- 採点は手書きルール（作用の理解30／希望との一致30／維持20／費用・期間10／経過評価10）。生成AIに正解判定を委ねない。
- ケースを増やすには `src/data/cases.ts` と、必要なら `imageAssets.ts` の状態・`faceStyles.ts` の仮イラスト差分を追加します（`npm test` が整合性を検証）。
